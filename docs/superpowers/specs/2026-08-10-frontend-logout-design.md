# 前端退出登录设计

## 目标

为已登录用户提供可见的退出入口，使其可以清除当前 Cookie 会话并回到登录页，从而切换或注册其他账号。

## 范围

- 在工作区页面右上角、用户邮箱旁增加“退出登录”按钮。
- 点击后请求既有的 `POST /api/auth/logout` 接口。
- 请求期间按钮显示“退出中…”并禁用，避免重复提交。
- 请求完成后将应用内 `currentUser` 设为 `null`，由受保护路由跳转到 `/login`。
- 请求失败同样清除前端会话状态，避免用户被卡在过期或无效的本地登录态中。

## 非目标

- 不修改 NestJS 退出接口、Cookie 属性或鉴权 Guard。
- 不创建公共导航栏，不为项目页、看板页重复添加退出按钮。
- 不增加依赖、全局状态库或持久化登录状态。

## 数据流

`WorkspacePage` 接收由 `AppRoutes` 管理的退出回调。按钮调用 `apiRequest<void>('api/auth/logout', { method: 'POST' })`；无论请求成功或失败，回调都会将 `currentUser` 置空。React Router 随即把受保护的 `/workspace` 重定向至 `/login`。

## 测试

新增工作区页面测试，断言点击按钮会发送 `POST /api/auth/logout`，并在请求完成后调用传入的退出回调。保留现有团队加载和创建测试。
