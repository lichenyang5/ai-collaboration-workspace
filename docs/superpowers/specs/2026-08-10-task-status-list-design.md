# 任务状态列表设计

## 目标

将项目任务看板从三列同时展示改为状态切换式的单列长条列表，降低任务较多时的视觉拥挤。

## 交互

- 页面展示“待办”“进行中”“已完成”三个状态切换项及各自数量。
- 默认选中待办；点击切换只读取已加载的 `board.columns`，不额外请求接口。
- 当前状态下的任务按长条卡片纵向展示：标题和描述位于左侧，负责人、优先级和截止日期位于中部，编辑和状态流转操作位于右侧。
- 调用现有移动接口成功后，任务会从当前列表消失，状态数量随 `board` 更新即时变化。
- 窄屏时信息和操作垂直排列，不产生横向滚动。

## 边界

- 不修改任务创建、编辑、分配、移动接口及其数据结构。
- 不修改 AI 草稿生成和确认创建流程。
- 不新增依赖或路由。
